# ととのえ献立（デモ版）

家族一人ひとりの年代、健康の目標、アレルギー、苦手な食材に合わせて、1週間の夕食の献立（主菜・副菜・汁物）を提案する Web アプリのデモ版です。

> 家族とレシピは架空のもので、栄養の値はデモ用の概算です。

## できること

| 画面 | 内容 |
|---|---|
| 献立 `/plan` | 7日分の献立、1日ごとの塩分・野菜・たんぱく質・エネルギーと目安の判定、「なぜこの献立？」、1品の入れ替え、料理ごとの好評／不評、「作った」とひとことメモ |
| レシピ `/recipes/[id]` | 家族の人数と年代に合わせた材料の量、作り方、栄養、アレルゲン |
| 買い物 `/shopping` | 1週間（または選んだ日）の材料を合算し、売り場の順に表示。チェックしながら買える |
| 家族 `/household` | 家族の追加と編集（年代、健康の目標8種、アレルギー9品目、苦手な食材）、調理時間 |
| モニター検証 `/insights` | 実行率、好評／不評、栄養の目安を満たした日数、家族のメモ、CSV の書き出し |

## 献立の作り方

- **ルール（デモモード）**：`src/lib/planner.ts`。アレルゲンと調理時間で候補を絞り、家族の目標、苦手な食材、評価、前日との変化、1日の塩分の予算で点数をつけて選ぶ。理由はプログラムが計算した数値から作る。
- **AI（Claude）**：`src/lib/ai.ts`。サーバーに `ANTHROPIC_API_KEY` を設定すると有効。プログラムが絞り込んだ候補だけを渡し、Claude が家族の目標と評価を読み取って選び、理由を書く。回答は決まった形（JSON）で受け取り、プログラムでもう一度検証する（存在しない料理、枠の違い、アレルゲン、主菜の重複）。問題があれば、ルールの献立に切り替える。
- **アレルギーは AI に任せない**：アレルゲンを含む料理は、AI に渡す前にプログラムで外し、AI の答えも再検証する。

## 技術構成

Next.js（App Router、TypeScript）、Tailwind CSS、Anthropic SDK（Claude Opus 5.5、構造化出力）、zod、Vitest、Vercel。
データはブラウザ（localStorage）に保存する。本番のモニター検証では、データベース（例：Supabase）への保存に置き換える。

```
src/lib/recipes.ts    レシピ48品（主菜24、副菜18、汁物10）と栄養の目安、アレルゲン
src/lib/planner.ts    ルールによる献立の作成、入れ替え、理由、検証
src/lib/ai.ts         Claude による献立の作成と検証
src/lib/shopping.ts   買い物リスト
src/lib/store.tsx     ブラウザへの保存
src/app/api/plan      献立を作る API（AI が使えるかどうかで切り替え）
```

## 起動とテスト

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 献立のルール、アレルゲンの除外（300世帯で確認）、AI の回答の検証、買い物リスト
```
